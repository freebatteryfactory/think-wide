1. CLOSED by PR #31 (T10). `submitProposal` and `beginHostRun` are bound at `8ba4302`.
   The loop test in this PR still publishes through `internal.runs.publish`; moving it to
   the public host path is a follow-up, and PR #27 already covers the MCP path.
2. CLOSED by PR #20 (T09). `prepareHandoff` and `readHandoff` are bound at `8ba4302`.
   The brief step is covered by PR #27 (`t11-mcp-handoff.test.ts`), not by this PR.
3. `searchSources` and `readGuidance` have no public handler; `getCapabilities` reports
   `searchModes: []`. T07's search code is not reachable as an operation. Owner: Eassa.
   Without it the demo is browse plus exact read, and must say so.
4. On `andrew/I01-identity` (`62dd428`) the browser never gives Convex a token. WorkOS
   login works and `convex/auth.config.ts` trusts the WorkOS issuer, but the root route
   mounts the plain `ConvexProvider`, not an authenticated one. Every browser call to
   Convex is anonymous and the handlers answer `unauthenticated`. Login is proven;
   login-to-backend identity is not. Owner: Andrew (I01).
5. OPEN, found while reviewing merged T10 at `76c193b`. Public `submitProposal` publishes
   a source ref whose `digest` does not match its bytes. A scratch probe against the real
   handlers submitted an all-zero digest, and separately a real digest with a different
   byte range; both were published and stored unchanged in `acceptedFindings`.
   `validateIndexedRef` checks repository, commit, blob and range, never the digest. This
   is evidence integrity, not cross-principal disclosure. By reading, the brief step
   re-reads bytes and compares digests (`verifySources` in `convex/lib/handoffs.ts`), so a
   forged ref should fail there with `source_unavailable`; that path was not tested. Codex
   raised the same point on PR #31 with no reply. Owner: Eassa. Probe kept outside the repo.
6. Local-demo has one fixed principal. Every agent on the stdio path is the same identity
   with the same grants. There is no per-agent authorization and A/B cannot be shown
   through MCP in this mode.
